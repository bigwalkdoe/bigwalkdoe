## The Spectre Ecosystem

A family of opinionated, config-driven tools for Linux system administration: bootstrap, harden, maintain, and monitor.

| Project | Purpose | Stack |
|---|---|---|
| [spectre-suite](https://github.com/bigwalkdoe/spectre-suite) | Maintenance, backup, and monitoring automation behind one CLI | Python |
| [spectre-agent](https://github.com/bigwalkdoe/spectre-agent) | Autonomous AI engineering OS for Fedora — agents, workflows, plugins, daemon | Python |
| [spectre-security](https://github.com/bigwalkdoe/spectre-security) | Defense-in-depth baseline with compliance monitoring, drift detection, and SBOM generation | Shell |
| [spectre-backup](https://github.com/bigwalkdoe/spectre-backup) | Encrypted, automated, versioned backup platform for Fedora workstations | Shell |
| [spectre-docker](https://github.com/bigwalkdoe/spectre-docker) | Hardening bootstrap for fresh Ubuntu/Debian servers with Docker | Shell |
| [spectre-k8s](https://github.com/bigwalkdoe/spectre-k8s) | Hardening bootstrap for fresh Ubuntu/Debian servers with single-node k3s | Shell |
| [spectre-kde](https://github.com/bigwalkdoe/spectre-kde) | Reproducible KDE Plasma config for a polished macOS-inspired Fedora workflow | Shell |
